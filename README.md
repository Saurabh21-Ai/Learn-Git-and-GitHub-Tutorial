# Learning Git and GitHub
This project is for Git tutorial, where you could learn requirment of Version Control System to upload your local working directory on GitHub. 

## Provide Notes
PDF files along with projects are provided for better understand. The PDF notes use **terminal screenshots** and **workflow pictures** for easy to understand.

## Languages Used
This tutorial uses **Python files** to make projects and commits, don't need to install external library to run. 

### Some basic Commands
`git init` or `git clone <url>` → For initialization git in directory. <br>
`git config user.name` → Specific for project. <br>
`git log` <br>
`git pull` <br>

### Some advanced Commands
```git config --global init.defaultBranch main
git log --oneline -5
git pull --rebase origin main
git switch -c new_branch 
git stash drop stash@2
```
